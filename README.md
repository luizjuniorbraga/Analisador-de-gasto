# 💰 Analisador de Gastos

Uma aplicação web simples, moderna e eficiente para controle de finanças pessoais. O projeto permite cadastrar, visualizar, filtrar e remover despesas, salvando os dados diretamente no navegador do usuário.

🔗 **Acesse o projeto online:** [Analisador de Gastos] https://analisador-de-gasto.onrender.com/

## 🚀 Funcionalidades

- **Cadastro de Gastos:** Adicione despesas informando descrição, valor e data (opcional).
- **Resumo em Tempo Real:** Visualize o total gasto e a quantidade de itens cadastrados instantaneamente.
- **Filtro Inteligente por Período:** Filtre seus gastos para ver apenas o "Mês atual", "Mês passado", meses específicos ou "Todos os meses".
- **Exclusão de Itens:** Remova gastos indesejados com um clique.
- **Persistência de Dados:** Utiliza a API de `localStorage` do navegador. Seus dados não são perdidos ao atualizar a página!
- **Design Responsivo:** Interface adaptável para computadores e dispositivos móveis.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído sem o uso de frameworks externos, focando no domínio das bases do desenvolvimento web:

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização moderna, uso de Flexbox/Grid e design responsivo.
- **JavaScript (Vanilla):** Lógica de programação, manipulação do DOM, eventos e manipulação de dados em JSON.
- **LocalStorage:** Armazenamento de dados no lado do cliente.
